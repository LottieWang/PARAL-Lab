Written assignments

Present the algorithm, explain why it works, and justify its complexity bounds. Use readable notation and state any assumptions. Typeset solutions in LaTeX and submit the requested PDF through Gradescope.

Coding assignments and projects

Implement parallel C++ algorithms in the provided course environment. Evaluate correctness, running time, and scaling across processor counts. Project 1 explores parallel sorting; Project 2 explores parallel BFS and includes a progress checkpoint.

Submitting code and a report

  1. Commit and push the version you want graded to your private assignment repository.
  2. Run git rev-parse HEAD and put the repository name and full commit identifier on the first page of your PDF report.
  3. Submit that PDF to the corresponding Gradescope assignment. The referenced commit must have been pushed by the applicable submission cutoff.

The Project 2 checkpoint and final report may refer to different commits in the same repository. Keep your solutions private.

What belongs in an experimental report?

  • Your algorithm, its analysis, and the motivation for each optimization.
  • A reproducible experimental setup: hardware, compiler, inputs, thread counts, and timing method.
  • Correctness checks, a suitable baseline, and measurements that show the effect of your changes.
  • Figures or tables with clear labels, plus an explanation of bottlenecks and unexpected results.
