Preparing for CSC 503

DePaul lists CSC 421 as the prerequisite for CSC 503. Review the topics below and become comfortable writing, compiling, and debugging C++ programs before tackling the programming work. See the official course listing.

Background checklist

  • Analysis: asymptotic notation, recurrences, divide-and-conquer, the Master Theorem, and the RAM model.
  • Sorting: sequential quicksort and merge sort, including their correctness and costs.
  • Data structures: arrays, linked lists, stacks, queues, hashing, and balanced search trees.
  • Graphs: directed and undirected graphs, adjacency representations, BFS, DFS, shortest paths, connectivity, and spanning trees.
  • Mathematics: probability, expectation, associativity, commutativity, and basic matrix operations.
  • C++: pointers and references, memory management, standard containers, and compilation.

Course computing environment

  1. Prepare your accounts. Have a GitHub account for private assignment repositories. Register a Globus ID for course cloud access; the instructor will provide the enrollment procedure through D2L.
  2. Use the assigned course machine. The planned workflow uses an instructor-allocated shared Chameleon instance. Connection information will be distributed privately.
  3. Complete Coding HW 0. Follow its README to connect, compile, and run the setup exercise and reduce code.
  4. Save your work. Push source changes regularly and retain reports locally. Cloud reservations expire, so follow the course migration instructions when a replacement machine is announced.

A replacement machine may have a new address or SSH host key. Verify the new connection details against the instructor’s announcement and follow the updated README. Office-hour support and detailed connection steps will accompany the assignment release.

Review resources

  • Parallel Computing: Theory and Practice for parallel-computing concepts.
  • CLRS for algorithms and analysis; check DePaul Library for access.
  • Your CSC 421 notes for sequential algorithms and data structures.
