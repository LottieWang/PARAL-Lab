AI Policy

DePaul University · CSC 503: Parallel Algorithms · Fall 2026

AI is able to solve many parts of the assignments fully autonomously. This makes it harder to deeply engage with and learn from the course material. All your code should be handcrafted by you directly.

The use of AI tools is permitted for answering high-level conceptual questions or for providing low-level programming documentation like function signatures and library APIs. However, AI tools are not permitted for implementing any part of any assignment. This includes both coding agents (e.g., Cursor Agents, Codex, Claude Code) and AI autocomplete (e.g., Cursor Tab, GitHub Copilot).

Student responsibilities

Concretely, students are expected to do the following:

  1. Each assignment repository will include an AGENTS.md file (inspired by this pedagogical prompt), which contains a pedagogical prompt. Coding agents that support repository instructions should read and follow this file. This file should not be modified in any way.
  2. When using online chat interfaces, paste the contents of the provided AGENTS.md file into the beginning of each conversation.
  3. In conjunction with the AGENTS.md file, it is okay to ask LLMs or coding agents to answer high-level conceptual questions or to pull up library APIs. It is not okay to ask LLMs or coding agents to write any code.
  4. Disable AI autocomplete in your IDE. Non-AI autocomplete, such as autocompleting function names, is permitted.
  5. This policy applies to both the assignments and any course leaderboards. All experiments you run should be written by you.

When in doubt

One rule of thumb is to ask yourself whether a member of the CSC 503 teaching staff would comply with your request in office hours. If not, then the request is likely not allowed under the AI policy. For specific cases, reference the provided AGENTS.md file, which contains more detailed descriptions of what is and is not allowed. If you are still unsure whether a specific use case is permitted, contact the teaching staff at lwang107@depaul.edu.
